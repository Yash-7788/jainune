## 1. STRATEGIC POSITIONING & EXECUTIVE MONETIZATION PHILOSOPHY

### 1.1 The Market Failure of Predatory Dating Apps
The mainstream dating ecosystem (Match Group: Tinder, Hinge; Bumble Inc.) operates on extractive, anti-user revenue mechanics:
- Artificial Scarcity: Obscuring inbound likes behind pixelated paywalls to induce curiosity-driven extortion.
- Shadow Deprioritization: Free user profiles are algorithmically suppressed into bottom percentile queues (ELO collapse) after a 7-day honeymoon period unless they purchase weekly boosts.
- Hostage Pricing: Subscriptions cost between INR 1,499 and INR 3,499 per month ($18 to $42/month), priced for Western purchasing power parity rather than domestic Indian realities.
- Churn Inevitability: Because pricing feels punitive, users churn immediately upon matching or uninstall in frustration after realizing matches are artificially throttled.

### 1.2 The Jainune Disruptive Axiom: High Value Behind Accessible 3-Digit Subscription
Jainune consolidates all novel interactive, voice, chemistry, and cultural features behind a high-value, highly affordable 3-digit subscription tier (Jainune+).
1. Free Tier provides a clean, dignified baseline: 10 daily likes, standard photo browsing, transparent inbound likes (no blurred paywalls), 3 active chats cap, and basic text messaging with graceful exit.
2. The Jainune+ Subscription unlocks the entire proprietary next-gen experience: Ambient Voice Canvas, 60-Second Voice Sparks, Blind 3-Question Dilemma Duels, Question Bounties, Chemistry Tickers, Sunday Brunch Circles, Bangalore Vibe Map, Wingman Endorsement Seals, Green Flag Capsules, and deep Jain dietary filters.
3. Pricing sits in the sweet spot of Indian subscription psychology: INR 499 / month (or INR 333 / month on the flagship quarterly plan). This is 70% cheaper than Hinge/Bumble, yet delivers immense ARR with 96% gross margins.
4. Micro-transactions NEVER lock, gate, or borrow from subscription features. They exist exclusively on a separate standalone Serendipity Arcade wall (kinetic wheel spins, lucky dice rolls) priced at 2-digit impulse amounts (INR 19 to INR 49) for spontaneous random matching.

## 7. RAZORPAY INTEGRATION & PAYMENT STATE MACHINE

### 7.1 Architecture: Subscriptions API vs Orders API
1. Razorpay Subscriptions API (UPI AutoPay & Recurring e-Mandate):
   - Handles Jainune+ plans (Monthly INR 499, Quarterly INR 999, Semi-Annual INR 1,699, Annual INR 2,799).
   - Automated pre-debit notifications via SMS/WhatsApp 24 hours prior to recurring debit under RBI guidelines.
2. Razorpay Orders API (Instant 1-Tap UPI Intent):
   - Handles all Serendipity Wheel micro-transactions (INR 19, INR 29, INR 49).
   - Triggers native UPI intent modal directly inside app, completing in under 4 seconds.

### 7.2 Database Schema: Subscriptions & Arcade Ledger

```sql
-- USER SUBSCRIPTION TABLE
CREATE TABLE user_subscriptions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    tier_id VARCHAR(32) NOT NULL, -- 'jainune_plus_monthly', 'jainune_plus_quarterly', etc.
    razorpay_subscription_id VARCHAR(64) UNIQUE,
    status VARCHAR(24) NOT NULL, -- 'active', 'halted', 'cancelled', 'expired'
    current_cycle_start TIMESTAMPTZ NOT NULL,
    current_cycle_end TIMESTAMPTZ NOT NULL,
    grace_period_end TIMESTAMPTZ,
    cancel_at_period_end BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- SERENDIPITY ARCADE WALLET & TRANSACTIONS
CREATE TABLE user_arcade_wallet (
    user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    available_spins INT DEFAULT 0,
    available_dice_rolls INT DEFAULT 0,
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE arcade_transactions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    action_type VARCHAR(32) NOT NULL, -- 'wheel_spin', 'dice_roll', 'arcade_3_pack'
    amount_inr NUMERIC(6,2) NOT NULL,
    razorpay_order_id VARCHAR(64) UNIQUE,
    razorpay_payment_id VARCHAR(64) UNIQUE,
    status VARCHAR(24) NOT NULL, -- 'initiated', 'captured', 'failed'
    created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 7.3 Webhook Handling & State Mutations
- `subscription.authenticated`: Activates Jainune+ privileges in Redis cache.
- `subscription.charged`: Extends `user_subscriptions.current_cycle_end`.
- `subscription.halted`: Triggers 72-hour grace period with gentle WhatsApp notification. Account remains active during grace window.
- `order.paid`: Captures micro-payment, increments user arcade token wallet instantly, and triggers kinetic wheel animation.
